# AR Object Detection Prototypes

Computer vision experiments for an augmented reality capstone installation exploring childhood nostalgia through physical toy interactions.

### Experiments

**1. [ArUco Marker Detection](aruco/)**

Uses OpenCV to recognize physical toys through printed markers.

**2. [YOLOE Object Detection](yoloe/)**

Uses a pretrained AI model to recognize toys without markers or custom training.

### Goal

Explore how physical toy recognition can be integrated with Meta Quest 3 and Unity to trigger audiovisual childhood memories when visitors interact with real objects.

### Current Status

Both methods have been tested using a Mac webcam. Meta Quest 3 integration and physical pickup detection are future development steps.
